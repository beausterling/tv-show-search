# TV Show Search

My JavaScript final project for my web dev course. You search for a TV show and the first 6 results from the TVmaze API show up with their poster, title and year.

Live site: https://beausterling.github.io/tv-show-search/

## Features

- Search bar that fetches shows from the TVmaze API
- Shows the first 6 results
- Sort by title (A to Z, Z to A) or by year (newest, oldest)
- Filter by genre
- Skeleton loading state while the results load
- Works on desktop and mobile

## Built with

- HTML, CSS and JavaScript
- [TVmaze API](https://www.tvmaze.com/api) (free, no API key needed). I used it instead of OMDb because it doesn't need a key.
